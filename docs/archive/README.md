# Documentation archive

These files preserve the original requirements and the reasoning behind earlier
increments. They are historical references, not current installation instructions.
Use the [current guides](../README.md) and [installation guide](../../INSTALL.md).

The [functional specification](specifications/functional-specification.md),

## Decision records

The `decisions/` directory records development, owner access, media/theme controls,
localization, restoration, metadata, Instagram imports and private deployment.
The old path-mounted Tailscale setup was superseded by the root-mounted setup;
the root deployment record remains useful for the existing host's routing history.

Obsolete Meta app-registration/setup instructions and the generic technical-design
prompt were removed during the documentation cleanup. The active integration is
described in [Instagram connection](../instagram-connection.md).
